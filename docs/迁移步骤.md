# 迁移步骤（coolhpj，XiaoQiang）

以下命令都在路由器上的 `/tmp/uu-remote-wol-router-helper-main` 目录里跑，一条一条粘，等提示符，跑前先核对。

> 老插件必须先在跑（种子已装、云已连），且不要先给老插件上自启动。迁移自己会给自启动，老插件的自启动反而会多一层备份/回滚。

## 第 0 步：确认老插件还在跑

```sh
cd /tmp/uu-remote-wol-router-helper-main
sh uu-helper.sh diagnose
sh uu-helper.sh preflight
df -h /tmp
df -h /data
```

- preflight 要过，/tmp 和 /data 都要有余量。
- diagnose 里 monitor/uuplugin 报 offline 可能是 busybox ps 截断的误报，以 `cloud_16000: online` 和 `netstat` 的 ESTABLISHED 为准；guardian offline 对老包是预期的。

## 第 1 步：stage 官方包（只写 /tmp）

```sh
sh uu-helper.sh stage openwrt-aarch64
```

要看到 `md5_check: pass`、`archive_check: pass`、`extract_check: pass`，最后 `STAGE_READY`，4 个文件齐。API 失败、MD5 对不上就停，老插件一点没动。

## 第 2 步：打补丁（只改本地 /tmp 副本，不改上游）

见 `patches/apply-xiaoqiang-ps-w.sh`，核心：

- 把 smoke-test、health、persist-common、uuplugin_monitor.sh 里的 `ps` 换成 `ps w`。
- 把 smoke-test 的 is_uu_running 改成同时认绝对路径 uu.conf。

打完用 `grep -n "ps w"` 验，`sed -n '89,92p'` 验 is_uu_running 那一行干净、无粘连。

## 第 3 步：smoke-test（临时测新版）

```sh
UU_RUNTIME_TEST_CONFIRM=TEMPORARY_RUNTIME_CHANGE UU_ALLOW_STOP_EXISTING=YES sh platforms/xiaoqiang/smoke-test.sh
```

- 会先停老插件，再临时起新版，最多 45 秒。
- 要看到 `uuplugin: online`、`guardian: online`、`cloud_16000: online`，最后 `SMOKE_TEST_PASS` 和 `evidence: /tmp/uu-wol-helper-stage/smoke-pass`。
- 测完不管过没过，都要验老插件回没回来：`ps w | grep uuplugin`、`netstat -an | grep 16000`。没回来就手动：

```sh
cd /userdisk/appdata/2882303761518031252
./xnetease-uu plugon
```

## 第 4 步：迁移安装（持久改动）

只有 smoke-pass 有了，才跑：

```sh
UU_XQ_INSTALL_CONFIRM=MIGRATE_XIAOQIANG_UU sh platforms/xiaoqiang/install.sh
```

- 会先备份到 `/data/uu-wol-helper-state/backups/`，再换文件、写 `/data/uu-v14/auto.sh` 并注册 firewall include，45 秒内健康不过自动回滚。
- 预期：`INSTALL_OK`，版本为 stage 那一步的版本，`service_activation: healthy_after_Xs`。

装完验：

```sh
sh uu-helper.sh diagnose
ps w | grep uuplugin
netstat -an | grep 16000
uci get firewall.uuplugin.path
df -h /data
```

diagnose 应为 healthy，firewall 路径应为 `/data/uu-v14/auto.sh`。

## 第 5 步：App 侧重绑（不要走全新安装向导）

- 不要走“安装路由器插件”向导：它做型号检测，RB06 会被判暂不支持加速。
- 走“添加硬件设备 → 合作款路由器”重新绑定，型号会显示为 OpenWrt，这是正常的。
- “OpenWrt下未发现主机连接”是游戏加速的主机列表，跟唤醒无关，不要追。

## 回滚

```sh
UU_XQ_ROLLBACK_CONFIRM=ROLLBACK_XIAOQIANG_UU sh platforms/xiaoqiang/rollback.sh
```

回滚会恢复备份的插件和 firewall 状态，但老插件不一定自动起，同样要 `ps w` / `netstat` 验，停了就手动 `./xnetease-uu plugon`。
