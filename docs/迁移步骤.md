# 路由器上怎么升级，说人话版

下面这些命令，都在路由器上的 `/tmp/uu-remote-wol-router-helper-main` 这个文件夹里跑，一条一条粘，别一次粘一堆。

## 开始之前

先确认老插件在跑，云也连上了。还没装老插件的，先回去装种子，种子没跑起来就别升级。

还有，老插件先别设开机自启动，升级的时候工具自己会设，现在设了反而多事。

## 第一步：检查

```sh
cd /tmp/uu-remote-wol-router-helper-main
sh uu-helper.sh diagnose
sh uu-helper.sh preflight
df -h /tmp
df -h /data
```

检查都通过了再往下走。如果检查里说插件没在跑，先别慌，可能是路由器看进程看不全，看看网络连接是不是真的通着，通着就是在跑。

## 第二步：下载新版

```sh
sh uu-helper.sh stage openwrt-aarch64
```

看到最后写着 STAGE_READY，四个文件都齐了，就算下载成功了。这一步只下载到临时文件夹，不动路由器原来的东西，很安全。

## 第三步：打补丁

跑这个脚本：

```sh
sh patches/apply-xiaoqiang-ps-w.sh
```

其实就是让路由器看进程的时候显示全名，不然工具老以为插件死了。打完检查一下，确认都是全名显示，再往下走。

## 第四步：临时试一下新版

```sh
UU_RUNTIME_TEST_CONFIRM=TEMPORARY_RUNTIME_CHANGE UU_ALLOW_STOP_EXISTING=YES sh platforms/xiaoqiang/smoke-test.sh
```

这一步会先把老插件停掉，再临时跑一下新版，最多等 45 秒。

要看到三个都在线，最后写着 SMOKE_TEST_PASS，才算通过。

测完记得自己查一下老插件回没回来：

```sh
ps w | grep uuplugin
netstat -an | grep 16000
```

没回来就手动跑：

```sh
cd /userdisk/appdata/2882303761518031252
./xnetease-uu plugon
```

## 第五步：正式换上去

只有上一步通过了，才跑这一条，这是真正改路由器的一步：

```sh
UU_XQ_INSTALL_CONFIRM=MIGRATE_XIAOQIANG_UU sh platforms/xiaoqiang/install.sh
```

它会先把老插件备份好，再换成新版，再设好开机自启动，45 秒内检查不过会自动退回去。

最后看到 INSTALL_OK，就算换成了。

换完再查一遍：

```sh
sh uu-helper.sh diagnose
ps w | grep uuplugin
netstat -an | grep 16000
uci get firewall.uuplugin.path
df -h /data
```

检查都正常，路由器这边就完事了。

## 第六步：手机上重新绑

别走“安装路由器插件”那个向导，它会说型号不支持。

走“添加硬件设备 → 合作款路由器”，绑好以后名字会变成 OpenWrt，这是正常的。

## 万一不行，怎么退回去

```sh
UU_XQ_ROLLBACK_CONFIRM=ROLLBACK_XIAOQIANG_UU sh platforms/xiaoqiang/rollback.sh
```

退回去以后，老插件不一定自己起来，同样要查进程和网络，停了就手动跑启动命令。
