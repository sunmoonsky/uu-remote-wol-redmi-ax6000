# 检查清单

## 迁移前

```sh
cd /tmp/uu-remote-wol-router-helper-main
sh uu-helper.sh diagnose
sh uu-helper.sh preflight
df -h /tmp
df -h /data
ps w | grep uuplugin
netstat -an | grep 16000
```

## 迁移后

```sh
sh uu-helper.sh diagnose
ps w | grep uuplugin
netstat -an | grep 16000
uci get firewall.uuplugin.path
df -h /data
cat /tmp/uu-v14-monitor.log
```

- diagnose 应为 healthy，版本为迁移后的版本。
- firewall 路径应为 `/data/uu-v14/auto.sh`。
- monitor 日志里 `read from guardian: 11486` 之类是 guardian 本地通信，不是报错。

## 唤醒前

- PN51 本机配置已完成，BIOS/网卡/快速启动已按 `docs/硬件与WOL设置.md` 配好。
- 手机 UU 主机加速器里路由器卡已绑定成功（合作款路由器，型号显示 OpenWrt 为正常），不是“联网失败”。
- 手机 UU 远程里进 PN51 的远程开机配置，辅助设备里出现路由器。
- PN51 真关机（不是睡眠、不是重启），关机后网口灯亮。
- 手机关 WiFi、只用移动数据，点远程开机。

## 重启复验（方便时做）

- 路由器重启后，跑迁移后的检查清单，插件应自动起来、cloud online。
- 再做一次移动数据唤醒。
