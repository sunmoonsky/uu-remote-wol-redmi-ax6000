# 用家里路由器，远程开电脑

## 这是干嘛的

电脑在家里关着，你在外面，用手机把它开机。
不用买新设备，就用家里那台红米路由器帮忙发一个开机信号。

就这么简单。

## 需要什么

- 一台红米 AX6000 路由器，家里在用的那台就行
- 一台华硕小电脑 PN51，Windows 系统，接网线
- 手机上装两个 App：UU 主机加速器、UU 远程，两个 App 用同一个账号登录

## 先把电脑设置好

电脑要能被远程开机，得先满足这几点，缺一个都不行：

1. 进 BIOS，把 ErP Ready 关掉，把 Power On By PCI-E 打开
2. 网卡设置里，电源管理那三项都勾上
3. Windows 的快速启动关掉
4. 关机以后，看一眼网口灯是不是还亮着，亮着才行

先在家里局域网里试一次本地唤醒，本地能开，再谈外网。

## 路由器上分两步走

### 第一步：先装一个老插件当种子

路由器上原来没有 UU 插件，直接升级是升不上去的，得先装一个 2023 年的老插件当底子。

装的时候别急着设开机自启动，先手动跑一下，看看插件是不是真的在跑、是不是连上网易的服务器了。能连上，再往下走。

### 第二步：升级到新版

老插件能跑了，再用迁移工具把它换成官方新版 v14.10.6。

顺序是：先检查、再下载新版、再临时试一下新版、最后才正式换上去。

正式换上去之前，工具会自动把老插件备份好，万一新版不行，还能退回去。

换好以后，路由器重启也能自己把插件再拉起来，不用每次手动跑。

## 手机上绑路由器，千万别走错路

手机上打开 UU 主机加速器，绑路由器的时候注意：

- **别点“安装路由器插件”那个向导**，它会说你这台路由器型号不支持，直接卡住。
- **点“添加硬件设备 → 合作款路由器”**，这条路不检查型号，能直接绑上。
- 绑好以后，路由器名字会显示成 OpenWrt，不是原来的 RB06，这很正常，就是新版插件的名字，别等 RB06 回来。

绑好以后，路由器下面显示“没发现主机连接”也不用管，那是游戏加速的主机列表，你的电脑跑的是远程控制，不是游戏加速，本来就不会出现在这里。

## 最后测试

1. 电脑开着，手机上打开 UU 远程，找到这台电脑，把远程开机设置走一遍
2. 电脑真关机，不是睡眠，不是重启
3. 手机把 WiFi 关掉，只用流量，打开 UU 远程，点远程开机
4. 等一两分钟，看电脑是不是真的开机了

真开机了，就算成了。

## 卡住了怎么办

这几个坑，都是实测踩过的，先看一眼再动手：

**路由器看进程看不全**
路由器那个看进程的命令，默认只显示一半名字，工具就以为插件没在跑。其实插件在跑，只是名字被截断了。解决办法很简单，看进程的时候加一个 w，让它显示全名，工具就认出来了。补丁在 `patches/` 里。

**临时测试完了，老插件没回来**
临时测试新版的时候会先把老插件停掉，测完应该自动把老插件拉回来。但老插件启动用的是完整路径，新版用的是相对路径，工具只认相对路径，就以为老插件没回来。其实老插件已经回来了，自己查一下进程和网络连接就能确认，没回来就手动再跑一次启动命令。

**改脚本的时候，& 会捣乱**
改脚本有个小坑：替换文字里如果有 `&`，它会被当成“整行原内容”又插一遍，结果一行变成两行粘在一起。避开的办法就是别写 `&`，用别的方式写重定向，补丁脚本里已经处理好了。

**手机上只看到自己，看不到路由器**
先确认三件事：手机和电脑是不是同一个账号；手机是不是连着家里路由器的 WiFi；路由器在主机加速器里是不是已经绑成功了。这三件有一个不对，手机上就只会看到自己。

## 要注意的两件事

1. 这里没有网易 UU 的程序本身，也没有你家的 WiFi 名、账号、网卡地址那些私人信息。原项目自己去下载，私人信息自己填自己的。
2. 路由器重启以后插件能不能自己起来，最好找个方便的时候重启一次、再测一次唤醒，重启也通了，才算彻底稳了。
