# 用红米 AX6000 远程开电脑｜UU 远程辅助开机实测

家里电脑关着，你在外面，用手机把它开机。不用买新设备，就用家里那台红米路由器帮忙发开机信号。

**本仓库只整合文档、步骤和本地适配补丁，不分发网易 UU 的程序，也不包含任何私人信息。**

> 非网易官方项目。**只有手机关掉 Wi-Fi、只用移动数据、把真正关机的电脑唤醒，才算成功。** 插件在线、路由器能联网，都不等于成功。

---

## 新手快速开始（3 步）

**第 1 步｜先把电脑设好。**

打开电脑 BIOS，把 ErP Ready 关掉，把 Power On By PCI-E 打开；网卡电源管理三项都勾上；Windows 快速启动关掉；关机后确认网口灯还亮着。建议先用网线，并在局域网里试一次本地唤醒，本地能开，再谈外网。

**第 2 步｜路由器上先装种子，再升级。**

路由器上原来没有 UU 插件，直接升级是升不上去的。先装一个老插件当底子，手动跑一下，确认它真的在跑、真的连上网易服务器了，再用迁移工具换成官方新版 v14.10.6。

这一步只启动工具，不会自动装插件；正式换上去之前，工具会先把老插件备份好，45 秒内检查不过会自动退回去。

**第 3 步｜手机上绑路由器，再真唤醒。**

手机连着家里路由器的 Wi-Fi，打开 **UU 主机加速器 → 路由器加速 → 合作款路由器**，把路由器绑上去。再在手机 **UU 远程** 里找到这台电脑，完成远程开机设置。最后电脑真关机，手机关掉 Wi-Fi、只用移动数据，点远程开机。

## 你应该看到什么？

完整链路应该是：

```
手机移动数据
    ↓
网易 UU 云端
    ↓
家里常在线的路由器（辅助设备）
    ↓
局域网 Magic Packet
    ↓
关机电脑开机
```

只满足下面这些，都还不能算最终成功：

- 路由器上有插件进程；
- 路由器能联网；
- 手机上能看到路由器；
- 局域网里手工唤醒能开机。

最终验收必须是：**手机关闭 Wi-Fi，仅使用移动数据，把真正关机的电脑唤醒。**

## 最常见的几个问题

### 一定要装路由器插件吗？

不一定。路由器已经有网易 UU 官方远程开机功能时，优先用官方入口；没有的话，再看本仓库的办法。电脑仍需事先配好 WOL，并在移动数据下完成真实开机测试。

### 辅助开机和远程控制有什么区别？

**辅助开机**由局域网里持续在线的路由器发送唤醒信号，让关机电脑开机；**远程控制**负责电脑开机后的连接和操作。本仓库只帮路由器承担前一种辅助角色，并不替代 UU 远程客户端。

### 官方安装向导说路由器型号不支持，怎么办？

不要走“安装路由器插件”那个全新安装向导，它做型号检测，红米 AX6000 会被判暂不支持。已经装好插件的情况下，走 **“添加硬件设备 → 合作款路由器”** 绑定，那条路不做型号检测。绑好以后名字会显示成 OpenWrt，不是原来的 RB06，这是新版插件的正常名字。

### 手机上只看到自己，看不到路由器，怎么办？

先检查三件事：

- UU 主机加速器和 UU 远程是不是同一个账号；
- 手机是不是连着家里路由器的 Wi-Fi；
- 主机加速器里路由器是不是已经绑成功了，而不是显示“联网失败”。

三件有一个不对，手机上就只会看到自己。

### 路由器重启后还要重新绑定吗？

本实测尚未做重启复验。迁移时已注册开机自启动，理论上重启后插件自己会起来，但跨重启后绑定是否还有效，需要等方便时重启一次、再做一次移动数据唤醒才能确认，不要把反复重新绑定当成稳定解决方法。

## 安全边界

本仓库：

- **不提供**破解、绕过设备安全限制取得 SSH/root 的教程；
- **不提交**网易 `uuplugin`、`xuplugin-guardian`、`xtables-nft-multi` 等闭源程序；
- **不包含**你家的 Wi-Fi 名、UU 账号、网卡地址等私人信息，示例里一律用占位符；
- 运行时只从网易官方通道获取插件，并做完整性校验；
- 一台设备通过，不代表所有同架构设备自动兼容。
